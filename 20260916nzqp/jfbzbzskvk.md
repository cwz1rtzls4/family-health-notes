# 山西医科大学第一医院春节门诊出诊安排

> 更新时间：2026-09-16 (UTC+8)

**2021年春节期间门诊出诊时间安排：**

2月7日（周日）        出周一门诊

2月11日~2月17日    上午正常门诊

2月20日（周六）      出周二门诊

近期，新冠肺炎疫情在国外持续肆虐且有变异病毒扩散蔓延趋势，国内部分地区多点散发。为确保广大人民群众的生命安全和身体健康，减少交叉感染，请前来就诊的患者及家属务必认真阅读本须知，并积极配合。
**门诊患者及陪同人须知**
1. 疫情防控期间，为了更好地满足广大群众的健康需求，山医大一院对非急诊患者实行网络预约挂号就诊，号源100%放入预约平台。患者应提前通过“网络预约”挂号，并根据时段错峰就诊，避免人员密集，安全有序就医。门诊设有老弱孕残专用通道，位于门诊西门。

目前，山医大一院门诊预约挂号方式包括：

微信公众号预约：健康山西微服务、近医通；

手机客户端预约：健康山西（山西挂号）；

电话预约：拨打114、12580、12320；

网络预约：登陆www.sxyygh.com；

2. 所有患者与陪同人员入门诊楼前请佩戴好口罩，主动提供健康码、行程码，经体温检测正常，方可进入门诊；

3. 请患者严格按照预约时间分时段进入门诊大厅，尽量减少陪同人员，候诊时自觉保持1米间距，就诊时遵守“一医一患一诊室”，在医院必须全程正确佩戴口罩；

4. 不会使用智能手机、无法出示健康码及行程码的老年人群，或者没带手机的人群，可在医院门口预检分诊人员帮助下填写纸质版流行病学调查表。
**发热、有呼吸道相关症状和有流行病学史的患者须知**
如您符合以下情况之一，请主动、如实告知工作人员，并遵循医护人员建议，真实、完整地登记有关信息后，按照医院安排到指定地点就诊：

1. 体温37.3℃以上；

2. 14天内有疫情中、高风险区的旅行史或居住史；

3. 14天内曾接触过来自疫情中、高风险区的发热或有呼吸道症状的患者；

4. 身边有聚集性发病或与新型冠状病毒感染者有流行病学关联；

5. 健康码或行程码异常者。

具有上述所列情况之一者，请不要作为陪同人员来院。
**核酸检测须知**
一、核酸检测预约流程

目前，我院已正式开通新冠核酸检测线上预约、缴费服务。筛查人员只需在手机或院内自助机按照指引进行操作即能完成检测挂号和缴费，在预约时间直接到采样点进行有序检测即可，无需再到现场排队挂号、缴费。节假日需在门诊二楼大厅方便门诊开化验单。

二、检测地点

山西医科大学第一医院1号楼东北角核酸采集点。

三、检测时间

工作日：8:00-12:00，14:30-18:00

节假日：8:00-12:00（春节假期只在2月13日、15日、17日上午开放）

四、取报告时间

上午10点前进行的核酸检测，一般在当天下午5-6点左右取结果；上午10点后进行的核酸检测，于第二天8点以后取结果。（节假日则都为第二日取结果）

五、取结果方式

凭条码在门诊、1号楼、5号楼、6号楼、医技楼的自助机均可打印核酸检测结果报告单。

六、电子票据获取方式

1. 网站查询：http://202.99.207.8008/bcweb/

2. 微信关注“电子票夹”小程序

3. 持患者身份证在门诊二楼大厅电子发票打印机打印即可。

七、其他注意事项

1. 核酸采集方式为鼻咽拭子；

2. 核酸检测无需空腹，采样前半小时不要吸烟、喝酒、嚼口香糖。
