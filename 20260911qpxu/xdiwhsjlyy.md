# 我院新生儿专家赴宁明县妇幼保健院开展业务指导工作

> 更新时间：2026-09-11 (UTC+8)

为深化医联体建设工作，推动优质医疗资源下沉，近日，由广西壮族自治区妇幼保健院新生儿医疗中心二病区副主任莫艳带领医护团队一行9人赴宁明县妇幼保健院开展业务指导工作。

此次培训采用理论与模拟操作相结合的方式，我院新生儿专家为宁明县妇幼保健院产科、麻醉科及新生儿科医护人员讲解了新生儿复苏流程，分享新生儿复苏经验，并重点进行了新生儿复苏的实操培训。
 / **授课交流现场**

在实操培训中，团队的经连芳主任医师、莫艳副主任医师、谭伟副主任医师及护理骨干通过分组带教的方式，手把手地对当地学员进行指导，通过分解操作和全流程的病例演练，学员们牢固地掌握了新生儿复苏的技能。最后，由谭伟副主任医师为大家讲解新生儿机械通气基本参数与调节，相互交流经验。
