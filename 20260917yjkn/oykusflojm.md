# 反复呕吐长达十年，背后竟是这种罕见病！

> 更新时间：2026-09-17 (UTC+8)

//  

本该好好享受退休生活的张阿姨，竟因为不明病因反复“呕吐”长达10年之久。是的，您没有听错，不是十分钟，也不是十天，更不是十个月，而是十年之久！

张阿姨（化名）从2012年开始，就出现了反复头晕、恶心、呕吐、四肢麻木的症状，每次病情发作持续干呕2小时，发作时间长达1到2个月。为此，张阿姨辗转多家医院的消化科、神经科就诊，做了胃镜、肠镜、头颅磁共振等一系列检查，但具体原因仍然诊断不明。

随着时间过去，张阿姨的症状逐渐加重，还间中出现了血尿、记忆力下降、视力下降的症状，最严重的一次竟然还出现了“不完全性肠梗阻”，为此，张阿姨还特地前往省级医院住院，复查了头颅磁共振，诊断为“可逆性后部白质脑病”和“抑郁状态”，经过治疗但效果依然欠佳。

长期遭受不明病痛折磨，张阿姨内心一直被痛苦煎熬。机缘巧合，张阿姨家属了解到惠州市中心人民医院神经内科为“神经系统遗传病/罕见病咨询中心”，如同黑暗中看到一丝光芒，张阿姨怀揣着希望前来就诊。

惠州市中心人民医院神经内科对神经系统疑难罕见病患者有着丰富的诊疗经验，然而面对张阿姨这种奇怪的症状，医生仍然有些摸不着头脑。

为进一步明确病因，惠州市中心人民医院神经内科罕见病小组开始详细研究和梳理患者历年来积攒的病例资料，然而这些资料并未给予医生新的方向。“但可以明确的是，张阿姨的症状并不是‘可逆性后部白质脑病’和‘焦虑状态’导致的。“可逆性后部白质脑病”顾名思义“可逆”，不符合张阿姨持续发展的症状。此外，虽然患者懒言，看上去像抑郁状态，但其实应该是一种发作性脑病状态。”神经内科罗伟良主任医师表示。

功夫不负有心人。仔细探查两天后，在患者一张磁共振的陈年老片上，医生通过仔细辨认锁定了一个暗藏的细节！ “虽然有些模糊，但这个表现与大脑皮质下“绸带征”非常相似”罕见病小组惊喜的发现。针对影像学胶片中出现的这一现象，小组结合国内外文献，猜想张阿姨患的很可能是一种2017年才开始被神经医学界所逐渐了解的罕见病——**神经元核内包涵体病（NIID）**。

 

▲张阿姨2012年的头颅磁共振成像未见明显异常

 

▲张阿姨2018年模糊的头颅磁共振成像可见若隐若现的大脑皮质下“绸带征”（**红色箭头**所示）及误以为可逆性后部白质脑病综合征的胼胝体病变（**黄色箭头**所示）

 

▲张阿姨2021年部分头颅磁共振（DTI+MRS+PWI）成像典型大脑皮质下“绸带征”，且往后头部发展（**红色箭头**所示）

神经元核内包涵体病（NIID）需要对患者进行全基因组测序和皮肤活检来进一步明确。然而，基因检测的结果却给罕见病小组成员泼了一盆冷水。张阿姨的检测结果显示，其遗传基因测序结果阴性，皮肤活检光镜弱阳性而高分辨电镜阴性。从检查结果来看，张阿姨无法确诊为NIID。

带着不折不挠的精神，罕见病小组再次分析了整个诊治过程和基因结果，并查阅了国内外医学数据库为数不多的个例病例报告后，坚持诊断方向。为此，医生再次申请采用2019年国内新发现的测序方法为患者重新检测基因。同时，邀请第三方合作机构采用省内首次使用的染色试剂和方法对染色皮肤病理切片重新复盘。

经过2个月漫长的等待，最终，新的检测结果印证了罕见病小组成员的想法！张阿姨的基因测序结果FRM1基因阴性而NOCTH2NCL基因阳性，结合再次复盘检测病理免疫结果 P62蛋白染色和泛素染色阳性，张阿姨被确诊的疾病为神经元核内包涵体病（NIID）！**距今为止，国内病例数据库对此病例只有二三十例报道，世界范围内报告也仅百余例。**

**科普知多D**

神经元核内包涵体病（NIID）通常为亚急性或慢性起病，病程1-44年不等，患者年龄跨度大，从2岁到78岁均有报道，男女患病比例约为1:2，其临床表现复杂多样，缺乏特异性。

成人型 NIID 主要症状包括: (1) 中枢神经系统受累表现: 痴呆、共济失调、发作性意识障碍、行为异常、亚急性脑炎样表现、 强直、震颤、癫痫发作、卒中样发作; (2)周围神经受累表现: 感觉障碍、远端肌力下降; (3)自主神经受累表现: 瞳孔缩小、 尿失禁、呕吐、晕厥。此外，本病也可出现假性肠梗阻、蛋白尿、狼疮肾炎等非神经系统表现。

抽丝剥茧寻真相，在惠州市中心人民医院神经内科罕见病小组的不懈努力下，这个被隐藏十余年的谜团终于被解开。通过1个月的综合治疗，最终，张阿姨症状好转，顺利出院。

2019年，神经内科被评为神经/遗传罕见病咨询协作网的分中心，近年来一直致力于提升疑难罕见病的诊断和治疗水平，让更多的罕见病患者受益。
