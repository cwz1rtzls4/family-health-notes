# 围观这位14岁的小医生怎样给患者看病

> 更新时间：2026-09-17 (UTC+8)

前几天医院来了一位14岁的小医生，穿着白大褂有模有样的他受到了医生和患者的一致好评。原来他的母亲是医院的一位医生，从小这位小男子汉的梦想就是能当医生，这次终于有机会能亲自体验一番白衣战士的日常工作，这也让他兴奋不已，让我们一起来看看发生了什么故事吧。

我叫唐博，今年14岁。今天，妈妈带我去医院参加社会实践活动。在去的路上，我很兴奋，因为今天的实践活动，我可是要去当一天的医师，一想到自己能穿上白大褂，像电视里的医师一样神圣，我就激动起来。

来到医院后，我领到了一件白大褂，衣服有点大，穿在我身上有点松松垮垮，可我莫名的感觉自己威风凛凛，霸气侧漏。我豪气万丈地走向医师办公室。看见这么年轻的“医师”，大家都投来了善意以及好奇的目光。面对这些目光，我突然有点不安起来，害怕自己不能胜任这份工作。

走入护士站，护士姐姐第一件事就是教我测量心率和血压。她拿起一个像衣服夹子一样的东西，告诉我这是血氧饱和度测量仪，我把它夹在自己的大拇指上。

测量仪上显示了二个数据，护士姐姐告诉我一个是心跳，一个是血氧饱和度，她还教我了心跳和血氧的正常范围值以及测量的意义。之后又教我使用血压测量仪，告诉我血压的正常值，什么是高血压，什么是低血压。

这时正好有一位老爷爷需要测量血压，于是我自告奋勇来帮他。这是我第一次测血压，心情十分紧张，大脑一片空白，有点无从下手。护士阿姨再次手把手的教了我测血压的方法，同时教我怎样登记血压和心率，而这位老爷爷也一直微笑的看着我，让我这位临时医生边学边操作，完全没有不耐烦。

做完这些后，护士阿姨就开始忙碌自己的啦，她们有的在帮病人服药，有的输液，有的的电脑前录医嘱。我很好奇，在病房四处看看。我一会儿看着谢力叔叔写病历，一会儿跟在其他医师叔叔去看病人。

这不，我和皮淼叔叔去病房看病人，走入一间病房，看见在靠窗的病床上，躺着一个脖子上围着纱布，插着一根管子的病人。他一见到皮叔叔，便伸出骨瘦如柴的手向他做着各种手势。皮叔叔跟我说：“这个病人喉咙出不了气，只能切开他的气管，插一根管子保障他的呼吸”。我看着这个病人，心生恐怖，感觉自己也无法呼吸了，没有等到皮叔叔和病人交流完，便偷偷离开了。

回到办公室后，我感叹：“这情景真是吓人，医师真不好当。”谢力叔叔听了笑了，对我说，“这就吓人了呀？来，唐博，我带你去看看另外一个病人吧”。我刚想拒绝，但转念一想，医师们每天都要面对的病人，我看看有何妨？于是我和谢叔叔一起进入了另一个病房。

相似的病房，同样靠窗的位置，一个老爷爷躺在床上。我们走至跟前，他依旧毫无反应。谢力叔叔拍了拍他的肩，他依然纹丝不动，仅有眼睛间或的转动，好似魂归天外。

谢力叔叔说：“他是个植物人，失去了自我意识，只能无意识的动弹，你看”，谢力叔叔掀开了被子，露出来病人的腿，只见病人的腿部肌肉非常的小，完全萎缩了。谢力叔叔接着说：“他不能运动，导致他的肌肉都萎缩了。而且他不能自主进食，只能我们喂他，你看见插入他鼻子的那根管子了吗？那根管子是胃管，直接插入他的胃，我们将食物打成粉，通过管子输入他的胃来补充他的营养”。我脑补了一下把管子从鼻子插入直到胃的场面，只觉得脊背上阵阵寒意，早上的早饭似乎在我的胃内翻腾。

走出病房后，我和谢力叔叔说：“这样活着真是生不如死呀”。谢力叔叔也长叹一声，感叹道：“天有不测风云，人有旦夕祸福啊！身体是生活的本钱，需要时刻保护”。

实践活动结束后，妈妈问我有什么感想，我幽幽地叹了口气，说：“健康，便是最大的幸福！”
