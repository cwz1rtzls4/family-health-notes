# 青大附院成功举办山东半岛生殖医学论坛暨山东省转化医学学会普通妇科第二次会议

> 更新时间：2026-09-16 (UTC+8)

近日，青大附院成功举办山东半岛生殖医学论坛暨2024年山东省转化医学学会普通妇科第二次会议。中国工程院院士马丁、中国科学院院士陈子江、青大第一临床医学院副院长孔心涓、青大附院生殖医院院长李豫峰等出席会议，省内外200余名生殖医学、妇科学专家参加会议。
 //
      马丁院士在致辞中指出，此次会议为全国生殖以及妇科领域专家搭建了高质量的学术交流平台，希望参会专家交流经验、创新理念，进一步推动山东半岛乃至全国生殖医学、妇科学事业发展，促进诊疗技术创新与服务水平提升，将发展成果真正造福于人民群众。

      孔心涓副院长表示，青大附院生殖医院积极引进国内外先进技术，以过硬的实力为不孕不育患者提供了优质的诊疗服务；妇科团队秉承“追求卓越、服务女性”的理念，学科实力不断增强。青大附院将进一步提升生殖医学、妇科学规范化诊治水平和辐射能力，为患者提供更高质量的医疗服务。

      李豫峰教授作为大会主席，简要介绍了青大附院生殖医院近年来发展情况，表示将进一步在科研攻关、医疗模式、服务创新等方面开展有益探索，力争实现新的突破。

       马丁院士在《面对国家重大需求，加快临床转化》讲座中强调了临床转化对于推动医学进步的重要性，指出医学研究与临床应用之间的桥梁作用不容忽视。他分享了自己团队在宫颈癌早期筛查分流、子宫内膜癌无创甲基化检查等领域的国家创新项目，并表示，科技创新要面向国家重大需求，面向人民生命健康。马丁院士的讲座引起了与会专家的热烈反响，大家纷纷表示，此次讲座不仅拓宽了视野，还为未来的临床实践提供了新思路。

       陈子江院士在《胚胎反复种植失败：为与不为》主题授课指出，胚胎反复种植失败是辅助生殖领域的一大难题，发生率高达10%-20%，给患者及家庭带来了沉重的负担。她分享了团队最新的研究成果，发现常用的免疫调节剂强的松并不能改善反复种植失败患者的活产率，反而可能增加生化妊娠丢失和早产的风险。陈子江院士强调，面对这一临床挑战，医生应谨慎选择治疗方案，避免盲目使用未经证实的药物。她呼吁业界加强合作，共同探索更有效的治疗方法，为患者带来福音。

       广东省妇幼保健院韦相才教授以《复发性流产诊治规范与生殖免疫学的未来思考》讲座中深入分析了复发性流产的诊治规范，并对未来生殖免疫学的发展方向提出了前瞻性的思考。韦相才教授指出，随着生殖免疫学研究的不断深入，免疫因素在临床生殖医学中的作用逐渐被人们所熟知。他强调，无论是卵母细胞和胚胎质量下降、子宫内膜功能失调或机体内环境稳态失衡，均与机体生殖免疫稳态失衡关系密切。他提出，未来从免疫角度探析人类生殖免疫功能障碍及生育力维持的关键机制，对人类生殖免疫学的发展将起到巨大推动作用。

       郑州大学第三附属医院生殖健康医院管一春教授在《女性全生命周期管理》提出，随着社会的发展和女性角色的多元化，女性全生命周期管理显得尤为重要。她倡导建立一个多学科合作的平台，以更好地服务于女性在不同生理阶段的健康需求，包括生育力保存、生殖健康、更年期管理等。她特别指出，对于肿瘤患者等特殊群体，生育力保存技术的发展和应用，为她们提供了更多的选择和希望。

     

       苏州大学附属第二医院的张弘教授就“复发性流产血栓前状态的筛查”进行了专业演讲。张弘教授指出，凝血功能异常，尤其是血液高凝状态——血栓前状态（PTS），是导致复发性流产（RSA）等不良妊娠结局的常见原因。她强调，抗凝和/或抗血小板治疗在RSA合并PTS患者的防治方面疗效肯定，但由于缺乏相应的规范，过度检查、过度治疗和超适应证用药等现象普遍存在。为了规范RSA合并PTS的诊治，国家妇幼健康研究会生殖免疫学专业委员会组织了多学科专家，根据RSA合并PTS的诊治现状，结合国内外最新的研究证据和进展共同讨论，制定共识，旨在为临床医师在临床实践中做出合理决策提供参考。他的演讲不仅为参会者提供了复发性流产血栓前状态筛查的最新研究进展，也为临床实践提供了宝贵的指导。

       中山大学孙逸仙纪念医院陈慧教授在《反复妊娠丢失与生殖免疫因素》授课中指出，反复妊娠丢失（RPL）是一个涉及多种因素的复杂疾病，其中生殖免疫因素扮演着重要角色。她强调，对于RPL的评估和管理，不仅要关注女性因素，男性因素同样不容忽视，特别是在胚胎发育过程中男性因素的影响。陈慧教授提出，对于RPL夫妇中的男性也应进行染色体核型分析，并合理选择胚胎植入前遗传学检测等。

       山东大学附属生殖医院颜军昊教授在《妊娠失败/流产中甲状腺抗体检测的临床意义》报告中强调了甲状腺抗体在妊娠失败和流产中的重要作用。他指出，甲状腺自身免疫疾病（TAI）是导致妊娠失败和流产的潜在因素之一，而甲状腺抗体的检测对于评估TAI患者的妊娠风险具有重要价值。颜教授详细阐述了甲状腺抗体阳性与妊娠失败之间的关联，并讨论了在临床实践中如何利用甲状腺抗体检测结果来指导治疗和管理，以降低流产风险并提高妊娠成功率。

       

        李豫峰教授的讲座《促排卵治疗过程中高剂量促性腺激素使用的思考》中指出，在促排卵治疗中，促性腺激素的使用剂量一直是一个备受关注的问题。高剂量的促性腺激素虽然可能在一定程度上提高排卵率，但也可能带来一系列不良反应和风险。因此，如何科学、合理地使用促性腺激素，以在保障患者安全的前提下提高治疗效果，是当前生殖医学领域亟待解决的问题。李豫峰教授强调，在使用促性腺激素时，应根据患者的具体情况和卵巢反应情况进行个体化调整。同时，医生应密切监测患者的激素水平变化，及时调整药物剂量，以避免过度刺激和不良反应的发生。

   

      上海市第九人民医院的匡延平教授就“延迟取卵在辅助生殖疑难案例处理中的价值”进行了深入的报告。匡教授通过多个案例分析，展示了延迟取卵在处理反复受精障碍、异常受精以及胚胎质量差等疑难案例中的重要性和有效性。他指出，延迟取卵可以预防早排卵，减少对内源性LH分泌的控制，使得促排卵方案更加简单灵活，并能提高取卵困难患者的获卵率，提升治疗效率。匡教授的研究还发现，延迟取卵显著提高了获卵数、获卵率以及优质胚胎数，同时不影响卵子成熟度、正常受精率及胚胎着床率。这一发现为辅助生殖技术中疑难案例的处理提供了新的策略和思路，具有重要的临床应用价值。

       "中南大学湘雅三医院徐大宝教授通过线上授课《宫腔粘连多学科诊疗实践》详细介绍了宫腔粘连的多学科联合诊疗管理（CTM）模式，该模式整合了妇科、产科、中医科、生殖医学中心等多个学科团队，围绕宫腔粘连治疗的前期、术期、术后期、备孕期、妊娠期和围产期六大环节进行综合处理。徐教授强调了宫腔粘连分离术（TCRA）的重要性，并分享了其团队在宫腔粘连治疗方面的创新技术，包括冷刀犁田式宫腔粘连分离技术以及宫腔支架的应用，这些技术旨在保护子宫内膜，减少术后再粘连的发生。此外，徐教授还提到了宫腔粘连治疗中的新进展，如四维超声的应用、“One-step”宫腔粘连分离术等手术技巧，以及干细胞移植等新的治疗方法。徐教授的报告为参会者提供了宫腔粘连诊疗的新视角和多学科合作的实践经验，对提升宫腔粘连治疗效果具有重要意义。

      青岛大学附属医院董教授在《风湿免疫疾病合并妊娠的诊治进展》 讲座中深入探讨了风湿免疫病在妊娠并发症中的作用，特别是系统性红斑狼疮（SLE）、抗磷脂综合征（APS）、干燥综合征（SS）、类风湿关节炎（RA）等常见疾病对妊娠的影响。她强调，这些疾病可能导致复发性流产（RSA）、早产、胎儿生长迟缓等不良妊娠结局。董教授还提到，妊娠期雌激素水平上升可能激活体液免疫途径，使得原有自身免疫病的活动度上升，病情进展，严重者可危及母婴生命。因此，妊娠合并风湿免疫病的免疫抑制治疗在减少妊娠不良事件发生率、控制和降低妊娠期疾病活动度中尤为关键。董教授的报告为参会者提供了关于风湿免疫疾病合并妊娠的最新诊治策略和研究进展，对于提高临床治疗的精准性和有效性具有重要意义。

       刘建新教授在辅助生殖技术领域拥有丰富的经验，特别在胚胎种植窗理论、卵巢功能减退、反复种植失败等方面有深入研究。他在《拮抗剂方案节点》报告中，详细讨论了拮抗剂方案在辅助生殖技术中的应用，包括预处理方式与时间的确定、促性腺激素（Gn）剂量与调整的评估选择、拮抗剂添加的时间节点、扳机时机与方式、胚胎移植策略的选择以及后期黄体支持方案等关键节点。这些节点的优化对于提高拮抗剂方案的妊娠成功率至关重要。刘建新教授的报告为临床医生提供了拮抗剂方案标准化应用的专家共识，强调了在不同卵巢反应人群中选择合适的促排卵方案的重要性。

      青岛大学附属医院的徐琳教授就“双胎妊娠的产前筛查与产前诊断”进行了专业报告。徐琳教授详细介绍了双胎妊娠产前筛查与诊断的技术规范，包括早孕期超声筛查、血清学筛查以及无创DNA检测（NIPT）的应用和适应症。她强调了孕早期超声筛查的重要性，特别是对胎儿颈项透明层（NT）厚度、鼻骨及静脉导管等染色体疾病相关软指标的检测。同时，徐教授也提到了双胎妊娠中不推荐单独运用血清学筛查，而早孕期血清学联合NT筛查可以提高21-三体筛查的准确性。此外，她还讨论了基于孕妇外周血胎儿游离DNA的非侵入性产前检测（NIPT）在双胎妊娠中的应用及其准确性。徐琳教授的报告为双胎妊娠的产前筛查与诊断提供了科学的指导和建议，对提高双胎妊娠的管理水平具有重要意义。

       青岛大学附属医院的刘世国教授就“子痫前期病因学研究”进行了深入的报告。刘教授的研究方向涵盖了子痫前期的多因素病因学，包括血管生成和抗血管生成失衡、免疫反应、氧化应激、炎症反应和遗传因素等。他的团队通过前瞻性收集孕妇资料，运用人工神经网络算法构建了子痫前期预测模型，筛选出包括孕前BMI、孕次、孕前是否吸烟、孕前是否饮酒、平均动脉压(MAP)、葡萄糖、AST/ALT、血清游离三碘甲腺原氨酸(FT3)、甲胎蛋白(AFP)等独立危险因素。此外，刘教授还探讨了PLCD3基因rs12946454位点多态性与山东汉族人群子痫前期遗传易感性的关系，为子痫前期的诊断和筛查提供了新的参考。这些研究成果不仅为子痫前期的早期识别和预防提供了科学依据，也为未来的治疗策略和干预措施的开发奠定了基础。

同时，会议设子宫内膜异位症疼痛管理指南巡讲、妇科肿瘤规范化诊治、子宫内膜异位症规范化诊治等分论坛，参会专家就学术交流内容展开了热烈讨论。

本次会议聚焦生殖医学及妇科学前沿进展，为相关领域专家搭建了良好的学习交流平台，展示了学科发展的新思路、新观念、新方法，对半岛地区生殖医学和妇科学事业高质量发展起到了积极的推动作用。
